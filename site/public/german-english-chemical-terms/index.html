German-English Chemical Terms

German and English inorganic chemistry share a common Latin/Greek root vocabulary for compound class names, but the suffixes differ systematically. This survey maps the German and English forms across the major inorganic compound classes where the -id/-ide suffix boundary applies.

The Core -id/-ide Boundary

The most important naming difference between German and English inorganic chemistry for this atlas is the compound class suffix: German uses -id, English uses -ide.

The Bisulfid/Bisulfide Axis

The most architecturally significant pair in this atlas is Bisulfid/bisulfide. This is the term at the German-English naming boundary where bisulfid.com sits. See Bisulfid vs Bisulfide for the canonical comparison.

German Suffixes Not in the -id Group

Not all German sulfur compound names use the -id suffix. The oxyanion sulfur compounds use different suffixes:

  • Sulfat (sulfate, SO&sub4;²¯) — uses -at suffix. See Sulfat.
  • Sulfit (sulfite, SO&sub3;²¯) — uses -it suffix. See Sulfite.
  • Bisulfit (bisulfite, HSO&sub3;¹¯) — uses -it suffix. See Bisulfite.
