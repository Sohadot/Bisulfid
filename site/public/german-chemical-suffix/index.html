Nomenclature · German -id Suffix · DE/EN Pattern

The German Chemical -id Suffix

In German inorganic chemistry, the suffix -id is used for compound classes where English uses -ide. This is a systematic feature of German chemical nomenclature, not an exception or error. bisulfid.com is built around this suffix boundary, with Bisulfid (the German form) as the domain identity term.

The -id Suffix: Scope and Meaning

The German -id suffix marks compound classes of the form “metal + anion” where the anion is a simple monatomic or specific polyatomic species. This covers:

  • Chalcogenides: Sulfid (S²¯), Oxid (O²¯), Selenid, Tellurid
  • Halides: Chlorid (Cl¹¯), Fluorid (F¹¯), Bromid (Br¹¯), Iodid (I¹¯)
  • Pnictides: Nitrid (N³¯), Phosphid (P³¯), Arsenid
  • Carbides: Carbid (carbon anion compounds)
  • Hydroxides: Hydroxid (OH¹¯)
  • Hydrides: Hydrid (H¹¯)

The Bisulfide Extension

Bisulfid extends the -id pattern to the HS¹¯ ion. Where Sulfid names the S²¯ compound class (analogous to oxide, chloride, etc.), Bisulfid names the HS¹¯ compound class — the hydrogen sulfide anion compounds. The prefix bi- here traditionally indicated the “hydrogen-” or “acid-” form of the anion (as in bicarbonate for HCO&sub3;¹¯).

-id vs -at: Two Distinct German Suffixes

The German -id suffix should not be confused with the German -at suffix, which is used for oxyanion salts (sulfate, carbonate, nitrate):

  • Sulfid (S²¯) — sulfide: simple anion; uses -id
  • Sulfat (SO&sub4;²¯) — sulfate: oxyanion; uses -at. See Sulfat.
  • Sulfit (SO&sub3;²¯) — sulfite: oxyanion; also uses -it, not -id. See Sulfite.

The -id/-ide boundary is between German and English forms of the same compound class names. The -at/-it distinction is within German, between different compound class suffix conventions.
