The -id/-ide Suffix Boundary

The most structurally important terminology difference between German and English sulfur compound names is the suffix. German inorganic chemistry uses -id where English uses -ide: Bisulfid/bisulfide, Sulfid/sulfide, Oxid/oxide, Chlorid/chloride. This is not an error — it is a systematic German nomenclature convention.

The domain name bisulfid.com reflects the German form precisely. See The Missing E for a full account of this suffix pattern, and Language Boundary for the DE/EN comparison table.

Disambiguation Terminology

Several sulfur compound classes are commonly confused with sulfides. These terms are included in the atlas specifically to draw boundaries, not to claim bisulfid.com covers them:

  • Bisulfite (HSO&sub3;¹¯) — a sulfite compound, not a sulfide. German: Bisulfit.
  • Sulfite (SO&sub3;²¯) — a sulfur-oxygen compound, not a sulfide. German: Sulfit.
  • Sulfat (SO&sub4;²¯) — German for sulfate; uses -at suffix, not -id.
  • Thiosulfate (S&sub2;O&sub3;²¯) — distinct from sulfide; contains both sulfur and oxygen.

German -id Form Index

The German -id suffix pattern extends well beyond sulfur compounds. The full set of German -id forms covered in this atlas:

  • Oxid — German for oxide (O²¯)
  • Hydroxid — German for hydroxide (OH¹¯)
  • Chlorid — German for chloride (Cl¹¯)
  • Fluorid — German for fluoride (F¹¯)
  • Bromid — German for bromide (Br¹¯)
  • Iodid — German for iodide (I¹¯)
  • Nitrid — German for nitride (N³¯)
  • Carbid — German for carbide (C-anion compounds)
  • Phosphid — German for phosphide (P³¯)
