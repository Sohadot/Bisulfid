Sulfur Terminology Glossary

A reference glossary covering the core sulfur compound terms and the German/English spelling boundaries that define the architecture of bisulfid.com.

Core Terms

Term Lang Description

The DE/EN Suffix Pattern

German chemical nomenclature systematically uses a shorter suffix for many compound classes where English uses the -ide / -ite ending:

  • English bisulfide → German Bisulfid
  • English sulfide → German Sulfid
  • English oxide → German Oxid
  • English chloride → German Chlorid
