# Bisulfid Design System

Proprietary, dependency-free visual language for the Bisulfid chemical-language control room.

## Structure

```
bisulfid-design-system/
├── DESIGN_SYSTEM_DOCTRINE.md   # Visual grammar and principles
├── tokens/                     # CSS custom properties
├── components/                 # Component primitives
├── assets/                     # Original SVG identity assets
└── engine/                     # Vanilla JS motion layer (no WebGL in 6N-A)
```

## Rules

- Zero external CSS/JS libraries, npm, or CDN
- Designer leads code — visual grammar first
- Source/claim truth is never hidden or implied
- Static-first; WebGL/WebXR deferred until foundation is stable
- Not integrated into `site/public/` in Sprint 6N-A

## Usage (future integration)

Link tokens and components from hardened publication frames only after template integration sprint authorization. Do not bypass governance banners or source-required markers.
