# Fourteen Thousand Publication Frame Model

**Sprint:** 6M-B  
**Fixed strategic target:** **14,000 governed pages minimum** at public launch

---

## What 14,000 means

Bisulfid.com is **not** a small website, glossary pilot, blog, or 500-page MVP. The **14,000-page governed launch corpus** is the minimum publication frame for sovereign sulfur intelligence at launch.

| Concept | Meaning |
| --- | --- |
| 14,000 pages | **Minimum launch corpus** — non-negotiable strategic objective |
| 500 pages | Advisory **readiness planning** threshold — not a launch target |
| 1,043 routes today | Early corpus registration — ~7.5% of launch target |
| Template frame | Rendering shell scalable to 14k+ without lock regression |

---

## Publication frame layers

```
Layer 0 — Governance locks (routes, sources, claims, policies)
Layer 1 — Build engine (dry-run, strict, mismatch validation) [6M-A]
Layer 2 — Template publication frame (this sprint) [6M-B]
Layer 3 — Governed render wiring (future)
Layer 4 — Quarantined QA samples (local, non-public)
Layer 5 — Controlled production build (future, gated)
Layer 6 — Public launch (future, explicit authorization)
```

---

## Template frame responsibilities at 14k scale

1. **Deterministic shell** — same governance slots for every page type
2. **Per-route lock respect** — status, indexable, sitemap, navigation from registry
3. **Multilingual** — EN/DE/AR now; FR/ES/JA/ZH future-ready
4. **Source/claim honesty** — never remove [SOURCE REQUIRED]; never imply approval
5. **Noindex default** — until explicit publication authorization per route
6. **No sitemap/nav leakage** — empty slots valid in locked posture

## Sample rendering vs launch

| Activity | Role in 14k pipeline |
| --- | --- |
| Template L1 validation | Frame contract proof |
| Build dry-run | Full corpus inspection |
| Local `site/_sample/` QA | Engineering proof only — **not** launch |
| Production build | Future — after all gates |

Sample rendering **does not** reduce the launch target. It **does not** substitute for corpus production waves.

## Corpus production path to 14,000

Current: **1,043** routes registered, **985** draft-backed.

Remaining registration and draft waves continue under existing source/claim gates until the **14,000-page** inventory is governed, then publication waves under Quality Gate — not before.

## Lock preservation at scale

At 14,000 routes the frame must still enforce:

- 0 accidental indexable output while locks active
- 0 sitemap XML generation without policy activation
- 0 navigation emission without config activation
- 0 publication inference from file existence

Sprint **6M-B** establishes the frame; build engine + registries enforce the locks.
