# Public Launch Next Actions — Post Sprint 6M-G

## Is the 14,000-page public launch foundation sufficient for first public release?

**Yes, as a controlled visibility foundation.** The 14,000 pages provide the first truthful public HTML asset. Full "public release" in the SEO/discovery sense requires opening indexation, sitemap, and navigation gates in separate authorized sprints.

## Before opening indexation

- [ ] Authorize indexation gate sprint with explicit robots policy
- [ ] Resolve or segment `[SOURCE REQUIRED]` pages for indexation eligibility
- [ ] Review claim boundaries for indexable terminology pages
- [ ] Validate CDN/hosting with `noindex` foundation first, then staged indexation pilot

## Before sitemap publication

- [ ] Activate `sitemap_policy.json` with governed URL selection rules
- [ ] Set `in_sitemap: true` only on authorized route subsets
- [ ] Generate sitemap via explicit build gate — never blind mass inclusion

## Before navigation exposure

- [ ] Curate navigation.json with governed subsets (gateways, hubs, verified references)
- [ ] Do not mass-add 14,000 routes to navigation
- [ ] Require source/claim posture review for navigated pages

## Production markdown/content rendering

Improvements remain. Current output uses publication frames with governed content sections. Rich markdown rendering and internal link emission remain future sprint work.

## Template refinements

Template layer passes validation. Refinements for multilingual typography, hreflang activation, and production body rendering remain on the roadmap.

## Source/claim blockers

Still matter. Public visibility does not reduce source/claim requirements. Registry locks remain non-negotiable until evidence-backed approval sprints.

## Multilingual expansion

EN/DE weighted at 14,000. AR/FR/ES/JA/ZH wave planning exists in L2 validators but requires dedicated expansion sprints.

## Recommended next sprint

**Sprint 6M-H (proposed):** Indexation pilot on a governed subset (e.g., 100–500 source-cleared gateway pages) with sitemap preparation planning — while continuing corpus expansion toward 100,000+.

## Why quality gates remain non-negotiable

Bisulfid is a sovereign reference asset. False source approval, false claim approval, or uncontrolled indexation would destroy trust at scale.

## Why visibility/publication remains the primary track

The 7,500-page RC proved engineering scale. The 14,000-page foundation proves public visibility. Continued expansion and gate opening proceed from this visible foundation — not from returning to quarantine-only output.
