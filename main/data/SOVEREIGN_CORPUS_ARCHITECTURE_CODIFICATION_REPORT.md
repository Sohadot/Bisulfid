---

## Strategic correction applied

Bisulfid.com is **not** a small chemistry site, thin glossary, blog, or indefinitely hidden internal corpus.

Bisulfid.com is intended to become a **visible, global, multilingual, sovereign-grade, reference-grade strategic digital asset** with:

- Deep conceptual architecture
- Strong SEO (including difference/comparison intent as core reference class)
- Strict governance
- Real pages with strong internal links
- No fake pages, broken links, technical/security weakness, or unsupported claims

## Scale mandate

**Minimum:** 14,000 real governed reference pages.

**Derivation:** dimensional intersection—not volume inflation:

```
term/entity × language × page_family × audience × source_posture × claim_posture × indexation × internal_link_role
```

**Multilingual floor:** 7 languages × 2,000 pages = 14,000 pages.

## Automation principle

Corpus generation must eventually be driven by:

```
route inventory + ontology + source registry + claim registry + page type registry + audience rules + production rules
```

**Not** manual one-page workflows. **Not** free-form LLM generation.

Sprint 6A creates execution primitives only. **No routes published. No pages generated. No HTML created.**
