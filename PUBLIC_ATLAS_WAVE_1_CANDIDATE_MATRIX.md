# Public Atlas Wave 1 — Candidate Matrix

## Selection Criteria

Pages selected for Wave 1 satisfy all of:
1. Content is factual and based on standard chemistry conventions
2. No performance, market, safety, or procurement claims required
3. Clear disambiguation function or compound class reference function
4. Internal linking potential (connects to ≥4 existing or planned pages)
5. No conflict with existing published routes
6. Bisulfide chemistry is the subject, not bisulfite sequencing
